# 📹 Project Video Demonstration

This folder contains references and assets for the Voice-Based Concept Understanding Analyser video demonstration.

## 🎬 Demo Video Highlights
The demonstration video covers:
1. System Architecture & Tech Stack overview.
2. Real-time audio recording and OpenAI Whisper transcription.
3. Sentence-BERT semantic similarity score calculation.
4. Google Gemini API fact-checking and AI suggestions.
5. Librosa filler word and pause acoustic analysis.
6. Generating and downloading the ReportLab PDF evaluation report.

## 📂 File Notes
- If uploading large `.mp4` video files to GitHub, consider using **Git LFS** (Large File Storage) or linking a YouTube/Google Drive video link in this file.
